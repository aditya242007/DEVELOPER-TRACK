# DevTrack

An engineering project and workflow platform for small development teams.

## Status

Planning is approved. Repository foundations are in progress.
No application features are implemented yet.

## Approved architecture

- TypeScript
- Next.js App Router frontend
- Node.js and Express REST API
- PostgreSQL
- Drizzle ORM
- Modular monolith
- Same-origin browser access through /api routing

## Scope control

The approved MVP scope is frozen.
Feature or technology additions require explicit approval.

Redis, microservices, AI, and real-time collaboration are excluded
from the MVP.

## Development setup

Application setup instructions will be added after the runtime,
